# Glow Up Kiosk Prototype

Prototype statico del comparatore audio Before/After.

## Funzioni
- Interfaccia touch ottimizzata per iPad
- Slider Before/After trascinabile
- Crossfade equal-power
- Audio demo generato in tempo reale con Web Audio API
- Nessun file audio esterno richiesto
- Installabile come web app dalla schermata Home di iPad

## Deploy su Vercel
Importa questa cartella/repository in Vercel come progetto statico.
Non serve alcun build command.
